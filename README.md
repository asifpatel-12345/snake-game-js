# 🐍 Classic Retro Snake Game

A lightweight, classic retro Snake game built using **HTML5 Canvas**, **CSS3**, and vanilla **JavaScript**. Features smooth controls, dynamic scoring, high score persistence using `localStorage`, and responsive styling.

---

## 🎮 Features
* **Retro Arcade Vibe:** Clean dark-themed UI with custom canvas borders and styling.
* **Dual Controls:** Play using both **Arrow Keys** (Left, Up, Right, Down) and **WASD keys** for convenience.
* **High Score Tracker:** Saves your highest score locally using browser `localStorage` so it persists even after refreshing the page.
* **Dynamic Gameplay:** Snake increases in speed and length as you eat food, with game-over detection for wall collisions and self-collisions.
